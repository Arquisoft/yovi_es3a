_En este apartado se hablará de la motivación y las consecuencias de cada decisión arquitectura que se ha tomado en el desarrollo del proyecto. Por tanto, no se contemplarán las decisiones tomadas por el equipo docente de la asignatura._

=== Servidor Oracle
Se ha decidido desplegar *YOVI* mediante un *Servidor de Oracle* por distintas *motivaciones*:

- *Escalabilidad*: Los servidores en Oracle permiten ampliar o reducir recursos según las necesidades del sistema.
- *Rendimiento*: La infraestructura está optimizada para cargas de trabajo intensivas y aplicaciones backend con alta concurrencia.
- *Soporte y Mantenimiento Gestionado*: Oracle proporciona herramientas de monitorización y gestión que facilitan la administración del servidor.

Las *consecuencias* que se pueden llegar a dar son las siguientes:

- *Dependencia del Proveedor*: La infraestructura queda ligada al ecosistema de Oracle.
- *Seguridad*: Aunque Oracle proporciona mecanismos de seguridad a nivel de infraestructura, la configuración de aplicaciones y accesos sigue siendo responsabilidad del equipo de desarrollo.

=== Base de Datos en MongoDB Atlas
Se ha decidido desarrollar la *Base de Datos* mediante *MongoDB* por distintas *motivaciones*:

- *Flexibilidad*: MongoDB es ideal para modelos que evolucionan, contienen relaciones flexibles o estructuras variables, como es el caso.
- *Alto Rendimiento*: MongoDB está optimizado para sistemas en tiempo real.
- *Resilencia Integrada*: Los Backups son automáticos

Las *consecuencias* que se pueden llegar a dar son las siguientes:

- *Riesgo de Desestructuración*: En caso de diseñar incorrectamente la Base de Datos, la flexibilidad se convertirá en un problema ya que generará documentos inconsistentes.
