Esta carpeta se ha creado para todos los archivos base que puedan ser públicos (es decir, que no contengan ninguna información
confidencial) respecto a la base de datos, tenerlos unificados al alcance de cualquier para entender mejor la aplicación:

Dentro de users, el archivo pruebaDBUSER.js muestra un ejemplo de como ejecutar todo y conectarse.
Cada desarrollador del proyecto, necesita su propio .env que NUNCA se debe de subir a github (especificado en el ignore)

El nombre de la Base de Datos es YOVI.

userCollection.js -> Representa la colección de las Base de Datos "usuarios"
botsCollection.js -> Representa la colección de la Base de Datos "bots"
gameYCollection.js -> Representa la colección de la Base de Datos "juegoY"
